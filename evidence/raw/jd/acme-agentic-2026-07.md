## Senior Agentic AI Engineer — Acme Corp

**About the role**

You will own the agent runtime that powers our customer-facing automation:
the orchestration layer, the tool surface, and the evaluation harness that keeps
it honest in production.

**What you'll do**

- Design and ship multi-step agents that plan, call tools, and recover from failure
- Own the orchestration graph: branching, retries, human-in-the-loop approval steps
- Build and maintain the offline evaluation suite; no agent change ships without a regression run
- Design tool interfaces consumed by models, including schema design and error semantics
- Make long-running agent runs resumable and debuggable

**What we're looking for**

- 5+ years backend engineering, of which 1+ building LLM-backed systems
- Hands-on with an agent orchestration framework (LangGraph, or a comparable state-machine approach)
- Strong grasp of structured output and function/tool calling — reliability, not demos
- Experience with agent state persistence and checkpointing
- Comfortable reasoning about cost and latency budgets per run
- Evaluation and tracing experience is a hard requirement, not a nice-to-have

**Nice to have**

- Multi-agent systems experience
- Contributions to open-source agent tooling
